¿Selección o Extracción de Características?

Existen dos grandes familias para reducir dimensiones. Comprender su diferencia es fundamental para no destruir la interpretabilidad de tus modelos de negocio.

checklist
ENFOQUE FILTRO / WRAPPER

Selección de Características

Variables Originales

Mantiene las columnas tal como son. Evalúa y filtra las variables menos informativas, quedándose con un subconjunto de las originales (ej. SelectKBest, RFE, regularización Lasso).

check_circle Ventaja: Máxima interpretabilidad; el negocio sabe exactamente qué mide cada variable.
remove_circle Límite: No fusiona variables correlacionadas en un único índice compuesto.
SelectKBest RFE L1 / Lasso
transform
ENFOQUE PROYECCIÓN LATENTE

Extracción de Características

Nuevos Componentes

Transforma y combina matemáticamente las variables existentes creando nuevas dimensiones ortogonales sintéticas (ej. Componente Principal 1, PC2 en PCA, o colectores en t-SNE y UMAP).

check_circle Ventaja: Captura la máxima varianza global combinada en pocas dimensiones.
remove_circle Límite: Pérdida de significado directo ("PC1 = 0.42*edad + 0.81*duración").

Calcula la razón de varianzas entre clases respecto a la varianza intra-clase. Cuanto mayor sea el valor F, más difieren los clientes 'yes' vs 'no'.

warning
¡Cuidado con la variable 'duration' en producción! ML ALERTA: FUGA DE DATOS (DATA LEAKAGE)

Aunque SelectKBest sitúa a duration con el valor F más alto del dataset, no siempre debes usarla para entrenar. Si el objetivo del negocio es priorizar a qué clientes llamar hoy antes de levantar el teléfono, la duración de la llamada es 0 segundos (aún no ha ocurrido).

Incluir duration produce métricas de precisión engañosas (>95%) que colapsan miserablemente en producción. La llamada larga es la consecuencia del interés del cliente, no una variable disponible previamente.

pipeline_selectkbest.py 
import pandas as pd
from sklearn.feature_selection import SelectKBest, f_classif
from sklearn.model_selection import train_test_split

# 1. Cargar el dataset bancario
df = pd.read_csv("dataset_selectkbest.csv")

# 2. Separar matriz X y variable objetivo y
X = df.drop(columns=['y'])
y = df['y'].map({'no': 0, 'yes': 1})

# 3. Partición de entrenamiento y prueba (Previene Data Leakage)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42
)

# 4. Instanciar SelectKBest con prueba ANOVA F
selector = SelectKBest(score_func=f_classif, k=2)

# 5. Ajustar solo en Train y transformar ambos
X_train_kbest = selector.fit_transform(X_train, y_train)
X_test_kbest = selector.transform(X_test)

# 6. Inspeccionar las características seleccionadas
selected_mask = selector.get_support()
selected_features = X.columns[selected_mask]
print(f"Top 2 Features retenidas: {list(selected_features)}")
# Output: ['duration', 'nr.employed']

Glosario Técnico de Machine Learning

PCA

Análisis de Componentes Principales: Proyección ortogonal no supervisada que maximiza la varianza en componentes latentes.

SelectKBest

Método de filtrado univariado que retiene las K características con mayor puntuación estadística calculada.

F-test (ANOVA)

Razón de varianzas utilizada para evaluar si las medias de los grupos difieren significativamente entre clases.

Data Leakage

Fuga de información del conjunto de test durante el preprocesamiento o la selección de variables previas a la partición.

Curse of Dimensionality

Dispersión exponencial del espacio métrico que causa escasez de datos y degradación del rendimiento en alta dimensión.
